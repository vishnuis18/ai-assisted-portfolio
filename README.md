# Antigravity Portfolio Learning Project 🚀

A modern, interactive personal portfolio website created as a learning project while exploring **Antigravity** and AI-assisted frontend development.

The goal of this project was not only to create a visually appealing portfolio website, but also to learn how to use Antigravity effectively for designing, developing, debugging, and improving a real frontend project.

## 📌 About the Project

This project is a **creative product designer portfolio website** that presents a modern dark-themed interface with interactive UI elements, portfolio projects, pricing sections, testimonials, and contact functionality.

I built and experimented with this project while learning how **Antigravity can assist in frontend development and UI/UX implementation**.

The website is built using:

* HTML5
* CSS3
* JavaScript
* SVG
* Responsive Web Design
* AI-assisted development with Antigravity

## 🎯 Purpose

The main purpose of this project was to:

* Learn how to use Antigravity for frontend development
* Understand AI-assisted website creation
* Experiment with modern UI/UX design
* Build interactive frontend components
* Improve my HTML, CSS, and JavaScript skills
* Understand how AI can help with designing and developing websites
* Practice modifying and improving an existing website concept

## ✨ Features

### 🎨 Modern UI/UX

* Dark modern interface
* Responsive layout
* Gradient effects
* Animated buttons
* Hover effects
* Card-based sections
* Custom SVG graphics
* Modern typography
* Smooth scrolling

The styling uses a dark color system with accent colors such as yellow, purple, pink, coral, and blue.

### ⏰ Live Clock

The navigation bar contains a real-time clock that updates every second using JavaScript.

### 🛒 Interactive Cart

The website contains a frontend shopping cart experience with:

* Add to cart
* Remove from cart
* Increase quantity
* Decrease quantity
* Cart item count
* Subtotal calculation
* Cart drawer

These interactions are implemented using JavaScript.

### 📂 Portfolio Filtering

Projects can be filtered by categories such as:

* All Projects
* Web Design
* Branding
* 3D Design

The filtering is handled dynamically using JavaScript.

### ❓ FAQ Accordion

FAQ items can be opened and closed interactively to provide a cleaner user experience.

### 💬 Testimonial Slider

The testimonial section includes:

* Previous/next controls
* Automatic slide switching
* Six-second autoplay interval

### 📩 Contact Modal

The website includes an interactive contact modal where users can open a contact form and submit their message through the frontend interface.

### 📱 Mobile Navigation

A mobile navigation menu is implemented using JavaScript and CSS to provide a better experience on smaller screens.
